# denkr 0.4.0

## Summary

denkr 0.4.0 makes the app easier to start using and more capable in day-to-day use. This update adds a clearer first-run setup, Desktop Connect foundations, voice messaging, richer chat actions, notebook UI blocks, better provider setup, native web search for more providers, and a launch-time update prompt for future beta releases.

## What changed

### Onboarding and first-run flow

- Added a clearer onboarding flow that helps new users get started faster.
- Added privacy, provider connection, wake, and waking screens for the first-run path.
- Improved provider setup during onboarding so connecting the assistant is smoother and easier to understand.
- Added a Say Hello path that sends the onboarding wake prompt into chat.
- Fixed wake prompt replay and message metadata issues after onboarding.

### Desktop Connect

- Added the Desktop Connect desktop app and its pairing/discovery flow.
- Added the desktop gateway runtime, protocol, and in-app connection entry points for the desktop companion.
- The desktop companion is currently macOS-only, still in development, and not publicly released yet.

### Chat, voice, and message actions

- Added voice messages and assistant voice settings.
- Made chat bubble text selectable.
- Added message action mode for chat messages, including a dedicated action bar and copy behavior.
- Grouped prose runs into a single selectable text wrapper so selecting assistant text is cleaner.
- Added formatted link previews with service icons, metadata, and local preview caching.
- Improved startup and interaction responsiveness.
- Fixed chat retry behavior and pasted image attachments.
- Improved how the assistant shows time and history so conversations are easier to follow.
- Fixed wake prompt replay and message handling.
- Adjusted composer controls and refined the assistant tone.

### Notebooks and saved content

- Added denkr UI blocks for notebook pages, including callouts, data tables, metric grids, progress blocks, and task lists.
- Improved notebook page rendering so saved assistant output can become more structured and readable.
- Updated notebook tools and storage so notebook pages can preserve these richer UI blocks.

### Providers, tools, and safety

- Added Zen, Kilo, and Cline provider support.
- Enabled native web search for Codex.
- Enabled native web search for OpenCode Zen through the Exa MCP service.
- Enabled native search for Kilo Code and renamed the Exa MCP service.
- Enabled Cline web search and fixed Cline sign-in.
- Improved provider account actions with clearer connection buttons and grouped provider models.
- Moved provider options into a bottom sheet modal grouped by provider.
- Improved web search routing and runtime output sanitization.
- Added runtime analytics and workflow tool tracing.
- Optimized the agent tool runtime with dynamic tool routing and tool request handling.
- Improved runtime workflow status so thinking, tool use, and workflow progress are clearer.
- Fixed a few release blockers and safety issues.

### UI and layout polish

- Migrated to sheet-backed selectors in settings and voice surfaces.
- Improved the memory views and shared sheet experience.
- Added blur and tint treatment to composer and bottom-sheet surfaces.
- Frosted the bottom-sheet backdrop with blur and tint.
- Redesigned the loading screen with animated details, then fixed loading screen colors.
- Fixed Arabic clipping and other RTL-related UI issues.

### Beta updates

- Added a launch-time app update prompt so future beta updates are easier to notice.
- Updated Android beta update handling and release documentation for the prompt behavior.

## How to use it

- Update from the Android beta channel once the `0.4.0` APK is published.
- Start with the new onboarding flow on a fresh install to get into the app faster.
- Try Desktop Connect if you want to test the early desktop companion flow.
- Use voice messages, image attachments, message selection, message actions, and link previews as you normally would to explore the new chat improvements.
- Open notebook pages that contain structured assistant output and check the new UI blocks.
- Check provider settings if you use Codex, OpenCode Zen, Kilo Code, Cline, Zen, or Gemini-related provider flows.
- If you use Arabic or other RTL languages, check that the interface still looks clean.

## Known issues

- Android beta installs are still manual outside Google Play.
- Desktop Connect requires pairing and is a separate companion app.
- Desktop Connect is still early and not part of the primary Android beta promise.
- iOS is not part of this public Android beta release channel yet.
- Provider availability and web search behavior can still depend on upstream provider account access, regional availability, and service limits.
