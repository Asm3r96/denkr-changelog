# denkr 0.6.0

## Summary

This release adds live Codex voice calls, connected YouTube access, per-chat model controls, and the latest Gemini and OpenAI model options. It also fixes the image attachment menu on Android and improves complex list rendering in assistant messages.

## What changed

### Live voice calls

- Start a live audio conversation from the composer when a ChatGPT/Codex subscription is connected.
- Voice calls use the active denkr assistant identity, memory, session context, and available capabilities.
- A voice call can hand an explicit request to the current text chat when you ask it to do so.

### YouTube account connection

- Connect YouTube from Settings → Services with Google's device authorization flow.
- Ask denkr to search your account, read subscriptions, playlists, notifications, history, and other account-aware YouTube data.
- Credentials stay in secure storage on the device and are never shown to the assistant.

### Chat and model controls

- Choose a provider, model, and supported thinking level for each chat from the composer.
- Reopening a chat restores its model and thinking selection.
- Added Gemini 3.6 Flash and Gemini 3.7 Flash effort options, Gemini 3.5 Flash Lite, and GPT-5.6 Luna, Sol, and Terra where supported by the connected provider.
- Added maximum thinking support for compatible GPT-5.6 models.
- Fixed image attachment menu taps being intercepted by the backdrop on Android.
- Improved nested list rendering in assistant messages.

## How to use it

- Connect a ChatGPT/Codex subscription, leave the composer empty, and tap the call action to start a live voice conversation.
- Open Settings → Services to connect YouTube.
- Tap the brain action in the composer to choose the provider, model, and thinking level for the current chat.

## Known issues

- Codex voice calls require a connected ChatGPT/Codex subscription and remain experimental.
- YouTube account access depends on YouTube's private TV API and may change without notice. Some write actions remain under investigation.
- Android beta installs are still manual outside Google Play.
- iOS is not part of the public beta channel yet.
