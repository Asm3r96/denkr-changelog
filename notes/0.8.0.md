# denkr 0.8.0

## Summary

This release fixes hidden Markdown tables in messages and adds horizontally scrollable tables that follow your appearance settings.

## What changed

### Tables in messages

- Markdown tables now show their headers and every row instead of disappearing from the message.
- Tables have rounded borders, accent-colored headers, alternating row backgrounds, and subtle dividers.
- Wide tables scroll horizontally within the message bubble. Long cell text wraps without truncation.
- Arabic and other RTL messages display the first column on the right and open the table at that edge.
- Cells preserve inline formatting, links, Markdown alignment, and line breaks.
- Table scrolling uses gesture handling that prevents table drags from becoming swipe-to-reply gestures.

### Text selection and saved pages

- Select text mode and plain-text extraction include every table header and row.
- Escaped pipes inside cells no longer split or drop cell content.
- The shared renderer also fixes tables in notebook pages.

## How to use it

- Open a message or notebook page containing a Markdown table.
- Swipe horizontally inside the table to see columns beyond the screen width.
- Use Select text to copy table contents as text.

## Known issues

- Android beta installs are still manual outside Google Play.
- iOS is not part of the public beta channel yet.
