# denkr 0.9.0

## Summary

This update replaces the bulky tables from 0.8.0 with compact, full-width tables and changes how table scrolling interacts with swipe-to-reply.

## What changed

- Chat tables now span the full message bubble width. Text outside tables keeps its normal padding.
- Cells use smaller body-font text, tighter padding, and top-aligned content, including bold text, links, and inline code.
- Muted headers and subtle horizontal dividers replace the heavy grid and alternating row backgrounds.
- Columns size to their content. Short tables fill the available width; wide tables scroll within the message.
- A thin, persistent scroll-position bar appears when a table is wider than the screen.
- Swipe-to-reply now explicitly waits for each table's horizontal scroll gesture to fail, instead of relying only on interruption suppression.
- Arabic tables start at the right edge. Content updates no longer reset the user's horizontal position.
- The shared table renderer also updates notebook pages.

## How to use it

- Open a chat message or notebook page containing a table.
- Swipe horizontally inside the table to see the other columns.
- Use the scroll-position bar to see where you are within a wide table.

## Known issues

- Native touch scrolling has not yet been verified on a physical phone for this release. Automated tests cover layout, RTL positioning, and gesture relationships.
- Android beta installs are still manual outside Google Play.
- iOS is not part of the public beta channel yet.
